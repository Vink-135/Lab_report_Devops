# LabConnect - Diagnostic Laboratory Portal

A complete web application for a diagnostic laboratory built with Flask and Bootstrap.

## Features
- Patient registration and login
- Book various lab tests
- Patient dashboard with booking history and report downloads
- Admin dashboard for overall statistics
- Admin capability to update booking statuses
- Admin capability to upload PDF reports for tests

## Tech Stack
- Backend: Python Flask
- Database: SQLite with SQLAlchemy ORM
- Frontend: HTML, CSS (Bootstrap 5), JavaScript

## Setup Instructions

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Default Admin Account:
   - Email: `admin@lab.com`
   - Password: `admin123`
